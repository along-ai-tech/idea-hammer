# 国际化（i18n）

## 何时需要

- 多语言用户（产品支持多语言）
- 多地区部署（不同 locale）

## 工具

| 框架 | 工具 |
|---|---|
| React | **react-i18next** / react-intl |
| Vue | **vue-i18n** |
| Python (Jinja) | **Babel** |
| Python (Django) | **i18n 内置** |
| Java | **Spring MessageSource** |
| Node.js | **i18next** |

## 强制规则

### 1. key 命名（点分 namespace）

```json
// ✅ 正确
{
    "user.profile.title": "用户资料",
    "user.profile.edit": "编辑资料",
    "order.detail.status.pending": "待支付",
    "order.detail.status.paid": "已支付",
    "common.button.submit": "提交",
    "common.button.cancel": "取消"
}

// ❌ 错误
{
    "title": "...",  // 无 namespace
    "userTitle": "...",  // 驼峰不一致
    "User_Profile_Title": "..."  // 大写不一致
}
```

### 2. 字符串外提

```typescript
// ❌ 错误：硬编码
<button>提交</button>
<h1>用户资料</h1>

// ✅ 正确
<button>{t('common.button.submit')}</button>
<h1>{t('user.profile.title')}</h1>
```

### 3. 复数处理（ICU MessageFormat）

```json
{
    "cart.items": "{count, plural, =0 {购物车为空} one {# 件商品} other {# 件商品}}"
}
```

```typescript
// i18next
t('cart.items', { count: 0 });  // "购物车为空"
t('cart.items', { count: 1 });  // "1 件商品"
t('cart.items', { count: 5 });  // "5 件商品"
```

### 4. 参数化插值

```json
{
    "user.greeting": "你好，{name}",
    "order.shippedAt": "订单于 {date} 已发货"
}
```

```typescript
t('user.greeting', { name: user.name });
t('order.shippedAt', { date: formatDate(order.shippedAt) });
```

### 5. 复数 + 参数

```json
{
    "notification.friends": "{count, plural, =0 {没有新好友} one {1 位新好友} other {# 位新好友}}"
}
```

## 后端

```java
// Spring MessageSource
@Component
public class ErrorMessages {
    @Autowired
    private MessageSource messageSource;
    
    public String get(String code, Locale locale, Object... args) {
        return messageSource.getMessage(code, args, locale);
    }
}

// 使用
String msg = errorMessages.get("user.not.found", LocaleContextHolder.getLocale(), userId);
```

## 翻译流程

1. **开发**：key 命名 + 默认语言（如英文）
2. **CI 卡门禁**：所有用户可见字符串在资源文件里
3. **翻译**：交给翻译服务 / 工具
4. **复审**：母语者校对

```bash
# 检测未翻译字符串
i18next-scanner --config i18next-scanner.config.js
```

## 反模式

- ❌ 硬编码中文字符串在代码里
- ❌ key 没有 namespace
- ❌ 复数用 if-else（用 ICU）
- ❌ 翻译缺失不报错
- ❌ 中英文混在一个文件
- ❌ 不测 RTL 语言（阿拉伯语 / 希伯来语）
