# 可访问性（a11y）

## WCAG 2.1 标准

三个等级：A / AA / AAA。Web 应用至少达到 **AA**。

## 强制规则

### 1. 语义化 HTML

```html
<!-- ❌ 错误 -->
<div onclick="submit()">提交</div>
<div class="nav">...</div>

<!-- ✅ 正确 -->
<button type="submit">提交</button>
<nav>...</nav>
```

### 2. 键盘导航

```typescript
// ❌ 错误：只用 click
<div onClick={openMenu}>菜单</div>

// ✅ 正确：键盘可访问
<button 
    onClick={openMenu}
    onKeyDown={(e) => e.key === 'Enter' && openMenu()}
    aria-haspopup="true"
    aria-expanded={isOpen}
>
    菜单
</button>
```

### 3. 焦点管理

```typescript
// Modal 打开时焦点移到 modal
useEffect(() => {
    if (isOpen) {
        firstFocusableRef.current?.focus();
    }
}, [isOpen]);

// 关闭时焦点回到触发元素
const triggerRef = useRef<HTMLButtonElement>(null);
const handleClose = () => {
    setIsOpen(false);
    triggerRef.current?.focus();
};
```

### 4. ARIA 属性

```html
<!-- 表单标签 -->
<label for="email">邮箱</label>
<input id="email" type="email" aria-required="true" aria-describedby="email-help" />
<p id="email-help">我们不会泄露你的邮箱</p>

<!-- 加载状态 -->
<button aria-busy="true" aria-live="polite">加载中...</button>

<!-- 错误提示 -->
<input aria-invalid="true" aria-errormessage="email-error" />
<p id="email-error" role="alert">邮箱格式不正确</p>

<!-- 图标按钮 -->
<button aria-label="关闭">
    <IconX />
</button>
```

### 5. 色彩对比度

- 文本：4.5:1（AA）/ 7:1（AAA）
- 大文本（≥ 18pt）：3:1（AA）
- 工具：[WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)

```css
/* ❌ 错误：低对比度 */
.button { 
    background: #fff;
    color: #aaa;  /* 对比度 1.6:1 */
}

/* ✅ 正确 */
.button {
    background: #fff;
    color: #333;  /* 对比度 12.6:1 */
}
```

### 6. 不要只靠颜色传达信息

```html
<!-- ❌ 错误 -->
<span style="color: red">必填</span>
<!-- 色盲用户无法识别 -->

<!-- ✅ 正确 -->
<span style="color: red">必填 *</span>
<!-- 或 -->
<span class="required">
    <IconAsterisk aria-label="必填" />
</span>
```

### 7. 表单验证

```typescript
// 实时反馈 + 错误信息
<input
    type="email"
    aria-invalid={hasError}
    aria-describedby={hasError ? "email-error" : undefined}
    onBlur={validate}
/>
{hasError && (
    <p id="email-error" role="alert">
        {errorMessage}
    </p>
)}
```

### 8. 跳过导航

```html
<a href="#main-content" class="skip-link">跳到主要内容</a>
<main id="main-content" tabindex="-1">
    ...
</main>
```

## CI 卡门禁

```yaml
- name: A11y check
  run: npx pa11y-ci --json > a11y-report.json
  # 或用 axe
- name: A11y check
  run: |
    npm install -g @axe-core/cli
    axe http://localhost:8080 --exit
```

## 反模式

- ❌ div + onclick（用 button）
- ❌ 只用颜色传达状态
- ❌ 图标按钮无 aria-label
- ❌ focus 样式去除（用 `:focus-visible`）
- ❌ Modal 没有焦点陷阱
- ❌ 视频无字幕
- ❌ 自动播放音频
- ❌ 表单无 label
- ❌ 跳过链接缺失
