# 流程：示例 — 0-1 首次创建

> 用户首次使用本 skill，从 0 创建产出物。

## 阶段 1：依赖检测

**目标**：确认前置输入是否就绪
**动作**：
1. 扫项目根目录找 `<required-file>`
2. 找到 → 进入阶段 2
3. 找不到 → 提示用户："缺 <required-file>，要先做 X 才能继续"
**完成**：依赖检测结论（已就绪 / 缺失什么）

## 阶段 2：访谈 / 信息收集

**目标**：收集必要输入
**动作**：
1. 读 contracts/input.schema.json 确认必填字段
2. 按字段逐项追问用户
3. 追问时引用 principles/ 下的纪律（如范围、复用）
**完成**：所有必填字段被用户确认

## 阶段 3：生成产出物

**目标**：按 schema 生成产出文件
**动作**：
1. 按 contracts/output.schema.json 字段填
2. 写到 contracts 指定的路径
3. 用 jq 验证产物符合 schema
**完成**：产出文件存在且 jq 校验通过

## 失败处理

- 阶段 1 缺依赖 → 退出，引导用户补
- 阶段 2 用户拒绝回答 → 退出，不写半成品
- 阶段 3 schema 不匹配 → 重写，不保存

## 完成标志

产出文件落地 + 通过 schema 校验 + 用户确认。
