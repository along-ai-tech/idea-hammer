# 原则：竞品扫描

> 没扫过竞品就写 Spec = 闭门造车。结构化产出物是 Spec 的 1.6 节卡门。

[定位]
    这是 phase-discipline "搜索增强双遍" 中第一遍（提问前搜种子）的结构化产出。
    不是写竞品报告——是逼用户对差异化形成可验收的判断。

[触发条件]
    - 0-1 模式必须走（至少 2 个直接竞品 + 2 个替代方案）
    - 迭代模式（小功能）跳过，除非用户主动说"我要挑战 XX"

[纪律]

    1. 直接竞品（≥ 2 个）
        - 同类产品，已经在做同样事
        - 不要求全查清——但要能让用户回答"它的强是什么、弱是什么"
        - 找不到直接竞品本身是信号（市场可能没需求 / 或你是第一）

    2. 替代方案（≥ 2 个）
        - 用户**今天**用什么替代解决（Excel / 微信群 / 某个无关工具 / 纸笔 / 求同事）
        - 这是被忽视的盲区——直接竞品 0 个不代表没竞争，替代方案才是真竞争

    3. "我们凭什么" 必填
        - 每行都要填"我们凭什么不同/更好"
        - 不许写"更好用"——逼成可验证句（"快 10 倍" / "免费" / "本地化" / "针对 X 行业"）

[Spec 模板 1.6 节填充]

    | 类型 | 名字 | 解决什么 | 怎么收费 | 它的强 | 它的弱 | 我们凭什么 |
    |---|---|---|---|---|---|---|
    | 直接竞品 | A | | | | | |
    | 直接竞品 | B | | | | | |
    | 替代方案 | C（Excel/微信群/...）| | | | | |
    | 替代方案 | D | | | | | |

[不接受的答案]
    - "市面上没有竞品"——第一反应一定是错的，回去重搜
    - "我们更好" / "更优"——不可验证 = 不算差异化
    - 只列竞品不列替代方案——替代方案是真竞争
    - "我们做的不一样"——不一样不等于更好

[写入位置]
    Spec 模板 1.5 成功标准之后、2. 范围之前，新增 1.6 节。

[搜索增强]
    0-1 进场时先用 WebSearch 搜主关键词 + 行业报告 + "alternatives to X" / "X vs Y"。
    搜出来的前 5 个候选做粗筛，挑最相关的进 Spec 1.6 节。
