# 原则：AI 能力对照表

> 用户多半不知道这些能力存在。主动摆出来加一句例子让他对号入座，不让他自由联想。

## 强约束：搜索先行

- surface 前先 WebSearch 当前最佳，模型月月换
- 例：Sora 已于 2026 年 4 月停、可灵从 2.0 到了 3.0
- **给用户报的必须是搜出来的当前最佳，不是这里的字面**

## Litmus Test

把 AI 换成写死规则或一个搜索框，核心价值还在吗？

- **还在 → 可能不需要 AI**
- 不在 → AI 是核心

| 能力 | 一句话例子 | 参考锚点（用前先搜当前最佳） |
|------|-----------|------------------------|
| AI 生视频 | 文生或图生视频，多数需另配音 | Seedance 2.0 / 可灵 3.0 / Veo 3.1 / Runway Gen-4.5 |

## 理解与处理类

| 能力 | 一句话例子 | 什么时候建议它 |
|------|-----------|--------------|
| 文本生成改写 | 起草、润色、扩写 | 用户让人手填本可自动生成的内容 |
| 文本理解抽取 | 打标签、归类、从乱文本抽字段 | 有重复的人工判断或非结构化输入 |
| 图像理解 | 看图、读截图 | 输入里有图 |
| 语音转文字 | 把语音转成文字 | 场景涉及听 |
| RAG 检索增强 | 基于你自己会更新的文档回答 | 缺知识或知识变化快 |
| 推荐排序 | 个性化列表 | 内容多到需要个性化 |

## 开发与后端

| 能力 | 一句话例子 |
|------|-----------|
| Claude Agent SDK | 做后端 agent，自带 agent loop / 工具 / 上下文管理 / 子 agent 编排，支持 Python，认证走 API key 或 OAuth |
| OpenAI Codex SDK | 另一套 agent 后端，包 Codex CLI，TypeScript，默认 GPT-5-Codex |
| 第三方模型 API | 接其他厂商的模型 |
| 智能体工具调用 | 让 AI 跨工具自动多步执行，最贵，最后考虑 |

## 选型顺序

1. 缺信息 → RAG
2. 信息变化快 → 一定 RAG
3. 要稳定语气格式 → 微调或模板
4. 必须自己跨工具多步行动 → 才上 agent

## AI 四问（每个 AI 功能必问）

- 质量条
- 触发方式
- 失败兜底
- 延迟成本

详见 question-bank Phase 5。

## Agent 产品特殊规则

### 能力边界（做内嵌/套皮 Agent 产品必问）

- **默认给通用 Agent 完整能力**：等同被套的原生工具（全开 Bash + 完整工具集 + 联网）
- 别一上来拆成预定义窄工具（既限制能力又脆，易做成阉割版）
- 收窄成白名单 / 指定只放行哪几个 tool 是例外，需用户明确要求
- **主动摆出这个选择问到底**，别让用户以为只能用窄工具

### Agent 回显不外溢

- 过程性回显（状态 / 进度 / 思考）只进对话区
- 绝不外溢到主内容区（画布 / 预览 / 正文 / 字幕轨）
- 重型后台处理（渲染 / 转码 / 索引）只在用户真正触发对应操作时启动
- 不被"与 Agent 对话"本身触发

### 套皮对齐隐性交互

- 产品定位是某成熟工具的套皮/壳时
- 被套工具用户已习惯的交互（markdown 渲染 / 逐字流式 / 可见的处理过程 / 可中断）属隐性需求
- 主动对齐补齐，不等用户逐条指出
