# 原则：Stage 1 审查维度（做对了没有）

> Stage 1 通过才进 Stage 2。Stage 1 有 HIGH 问题就停在 Stage 1。

## 功能完整性

- Spec 每条功能逐项对照代码
- 输出三态：**完整实现** / **部分实现** / **未实现**

## 引导真实性

- UI 占位符 / 提示 / 引导文案必须对应已实现的行为
- 揪出指向不存在功能的**死引导**（如 placeholder 写"输入 X 调用"但 X 无任何处理）
- 死引导 = 未实现

## UI 一致性

- 有设计稿 → 提取设计数值与代码逐项比对
- 对照 Design-Brief 的色彩、密度、风格
- 不止看组件名，要看实际渲染效果（按钮 / 间距 / 气质）
