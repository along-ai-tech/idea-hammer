# 原则：复用优先与设计参照

> 先复用 Design-Brief 和现有公共样式、组件，禁止自造命名空间 override。同语义有多套体系时选更高级的那套。

## 复用优先

- 动 UI 前先读 Design-Brief 和现有公共样式、组件，列出可复用项
- 新页面继承相邻同类页面的语义、交互、危险操作规则，不一页单造一套
- 复用对齐不止看组件名，要打开邻居基准页面实际对比渲染效果
- 改完 UI 主动自检渲染边界：按钮/文字不超容器、窄面板不挤爆（多按钮一行先估宽度，挤就拆行或图标化）、危险操作从主操作行分离并按 Design Brief 加确认

## 设计参照

- 有设计工具 MCP 连接时，每个 Task 前读取涉及页面和组件的精确数值：宽高、间距、字号、字重、颜色、圆角、阴影
- 每个 Task 都重新读，不凭记忆
- 编码后读代码实际值逐项对照，有偏差先修再提交
- 设计稿与 Design-Brief 冲突时以设计稿为准
- 无设计工具时以 Design-Brief 为参照；无 Brief 时继承项目既有页面先例，不自由发挥
