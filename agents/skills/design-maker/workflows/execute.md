# 流程：生成设计交付物

## 阶段 1：加载输入

**动作**：
1. 读 Product-Spec.md 提取 UI 功能
2. 读 Design-Brief.md 提取视觉方向
3. 确认设计工具（MCP）：Pencil / Figma

**完成**：输入就绪

## 阶段 2：提取清单

**动作**：
1. 页面清单（Spec UI 布局 + 功能 + 用户流程三处交叉）
2. 状态变体清单（默认 / 空 / 加载 / 错误 / 激活）
3. 可复用组件清单（按钮 / 输入 / 导航 / 卡片 / 标签）

**完成**：3 份清单

## 阶段 3：用户对齐

**动作**：
- 向用户展示交付物清单和总数
- 确认后开始

**完成**：用户同意

## 阶段 4：执行

**动作**：
1. 取设计工具 guidelines
2. 设变量（颜色 / 字体 / 间距 / 圆角）
3. 建组件（逐个截图验证）
4. 逐页面设计：
   - 用组件拼
   - 填真实内容（不用 Lorem ipsum）
   - 对照 Spec 和 Brief
   - 截图验证
5. 设状态变体

**完成**：所有页面 + 状态变体

## 阶段 5：交付

**动作**：
1. 完整性和一致性校验（对照 Spec 无遗漏）
2. 用 contracts/output.schema.json 校验
3. 输出报告引导 /dev-planner

**完成**：报告落地
